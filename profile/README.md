# Welcome to SorobanAgents 🛰️🤖

> **Autonomous AI Agent Scoped-Allowance & Micro-Settlement Protocol on Stellar & Soroban.**

SorobanAgents builds decentralized economic infrastructure enabling autonomous AI agents, LLM toolchains, and multi-agent swarms to securely execute micro-transactions, pay for inference, and interact with smart contracts on the Stellar network without human intervention or master key compromise.

---

## 🏛️ Flagship Protocol

### ⚡ [AgentRail](https://github.com/SorobanAgents/agentrail)
The autonomous execution rail for AI agents on Soroban.
- **🔐 Scoped Allowances:** Time-bounded, spend-capped session keys preventing treasury drain.
- **⚡ Sub-Cent Micro-Streaming:** High-frequency, sub-3-second USDC payments with near-zero network fees.
- **🛡️ Proof-of-Task Escrow:** Cryptographic SHA-256 output verification before fund release.
- **🔄 Soroban State TTL Keeper:** Automated rent bumping preventing smart contract archival.
